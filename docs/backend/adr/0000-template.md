### Rules for ADRs

1. **One decision per ADR.** If you're writing "and also", split it.
2. **ADRs are never edited after they're accepted**, except for the status line. To change a decision, write a new ADR and mark the old one `Superseded by …`.
3. **Number them in order**, and never reuse a number.
4. **Keep them short.** One to two pages. Link out for the details.
